# 🎮 Radha Mini Quiz Game

A small and fun interactive Python quiz game created as a beginner-level Python project. 😄

The game asks the player a few simple questions about Radha and calculates the final score based on the answers.

---

## ✨ Features

- 🎮 Interactive command-line gameplay
- ❓ 3 quiz questions
- ✅ Automatic score calculation
- 📊 Percentage calculation
- 🏆 Final result display
- 😊 Different messages based on the score
- 💻 Simple and beginner-friendly Python code

---

## 🕹️ How to Play

1. Start the game.
2. Choose whether you want to play.
3. Answer each question.
4. Get your final score.
5. See your percentage and result message.
