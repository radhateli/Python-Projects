# 🎓 Student Data Management System

A simple Python-based Student Data Management System that collects student information, calculates grades based on marks, and displays all student records.

## 📌 About the Project

This is a beginner-friendly Python mini project created to practice basic Python programming concepts such as:

- Variables
- User Input
- Conditional Statements
- For Loops
- Lists
- Dictionaries
- String Formatting
- Basic Data Storage

The program allows the user to enter information for multiple students and automatically assigns a grade according to their marks.

## ✨ Features

- Enter the total number of students
- Store student name
- Store roll number
- Store marks
- Automatically calculate grades
- Store student records using dictionaries
- Display all student information at the end

## 🧮 Grading System

| Marks | Grade |
|-------|-------|
| > 95  | A |
| > 80  | B |
| > 60  | C |
| ≥ 33  | D |
| < 33  | F |
